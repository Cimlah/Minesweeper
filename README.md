# Minesweeper game

A minesweeper game created as a uni project.

## Major functionalities

Major functionalities of this game are:

- ### Core mechanics of a standard Minesweeper game:

  - Map generation
  - Marking cells
  - Revealing cells
  - Timer
  - If a bomb is revealed, end the game
  - Choosing a pre-defined map size or creating a custom one

* ### Power-ups:

  - Time freeze - freeze timer for a short period of time
  - Shield - protect against one bomb reveal
  - And others

* ### Player statistics:

  - Total time played
  - Total games played
  - Wins
  - Losses
  - Fastest clear time
  - Success rate

* ### Game modes:

  - Classis minesweeper
  - Time-attack - race against the clock to clear the board or a certain number of cells
  - And others

* ### Achievement system

  - First Blood - win your first game.
  - Mine Sweeper Master - clear 100 mines
  - Speed Demon - clear a medium board in under 60 seconds

* ### Theme creation
  Create your own style of a board. Be able to adjust:
  - colors
  - borders
  - change bomb icon
